# 17 · 早期聊天窗口 / Early Chat Window

批次 D；101–107 秒。原创桌面聊天软件「栖线」，层叠小窗、联系人列表和骑行低帧动图；不使用真实软件名称、图标或界面布局。

- 色票／材质：灰蓝 `#bccbd0`、深蓝 `#3a6477`、奶白、少量草绿；像素边框、固定压缩噪点和抖动，不显示实现说明。
- 主体／骨骼：动图中的小鹈鹕采用独立简笔造型，共享腿脚和轮相，10 Hz 更新；外部窗口与镜头平滑。道路 `y=802` 隐喻为消息窗口底线，延展 `-500…1500`。
- 三小节：0–2 秒小窗弹出；2–4 秒新消息抵达，强拍抖窗，骑手低帧动图继续；4–6 秒关闭浮层后穿框。
- 标题：窗口标题区显示中文／英文／2000s，聊天正文不遮骑手。104 秒特写，102.3／104／106.3 秒三态，101／107 秒查边界和窗口抖动时间。
- 性能：桌面及窗口框缓存，噪点由固定帧索引生成；抖动按事件包络计算，不能修改 DOM 播放状态。
